# АвтоЗапис: мойки, шиномонтаж и СТО Киева

Мобильное веб-приложение (PWA) для Киева: найти мойку, шиномонтаж или автосервис,
сравнить цены и записаться онлайн на свободное время. Работает в браузере телефона,
ставится на главный экран («Добавить на экран „Домой“»), открывается без интернета,
в том числе во время отключений света. Интерфейс на украинском, цены в гривнах.

## Что умеет

- **Каталог мест** по категориям (мойка, шиномонтаж, СТО), поиск по названию, адресу и услуге,
  фильтры «Открыто сейчас» и «Избранное», сортировка по рейтингу, цене и отзывам.
- **Цены под вашу машину**: легковая, кроссовер или внедорожник/минивэн.
- **Карточка места**: часы работы, статус «открыто/закрыто», услуги с ценой и длительностью,
  кнопки «Позвонить» и «Маршрут» (Google Maps), отметка «Генератор: работает во время отключений».
- **Онлайн-запись**: выбор услуг → день (7 дней вперёд) → свободное время с шагом 30 минут.
  Итоговая цена и длительность считаются сразу.
- **Мои записи**: предстоящие и история, отмена, добавление в календарь (.ics с напоминанием
  за час), «Записаться снова».
- **Гараж**: свои машины с госномером, классом и размером шин.
- **Сезонная подсказка** в октябре–ноябре и марте–апреле: пора переобуваться.
- Светлая и тёмная тема, доступность (проверяется axe).

## Оплата «как на FunPay» (прототип)

Клиент не платит комиссию. Деньги удерживаются до выполнения работы, а комиссия
с точки (7%) берётся только при выводе средств. Правила задаются в `PAYMENT` в `app/data.js`.

1. **Оплата при записи.** Клиент получает 4-значный код и называет его мастеру после работы.
2. **Мастер вводит код** во вкладке «Для бізнесу», и деньги сразу попадают на баланс точки.
3. **Без кода** точка жмёт «Виконано». У клиента 24 часа, чтобы подтвердить или открыть спор,
   иначе деньги уходят точке автоматически.
4. **Доплата на месте:** точка запрашивает сумму с причиной, клиент соглашается или отказывает.
5. **Отмена:** за 2+ часа деньги возвращаются полностью, позже точка получает 50%.
   При неявке точка тоже получает 50%.
6. **Спор:** деньги замораживаются, модератор возвращает их клиенту или передаёт точке.
7. **Вывод:** точка видит «Доступно» и «Утримується», а при выводе показывается комиссия
   и сумма на карту.

Сейчас это демо: оплата имитируется, а данные клиента и точки хранятся на одном устройстве.
Для запуска нужен сервер и платёжный сервис с удержанием средств (UAPAY, Fondy и др.).

## Как заменить демо-места на настоящие

Все данные лежат в [`app/data.js`](app/data.js):

1. `CITY.name` — город (сейчас «Київ»), он добавляется к адресу при построении маршрута.
2. В `PLACES` замените демо-места на настоящие: название, категории (`wash`, `tires`, `service`),
   адрес, район, телефон, часы работы (`[9, 21]` или `null` для круглосуточных), рейтинг,
   число боксов и список услуг с ценами для трёх классов машин.

Сейчас в списке **вымышленные** места: улицы и районы Киева настоящие, а названия,
номера домов и телефоны придуманы для демонстрации.

## Запуск

```bash
cd autoservice
npm install
npm run serve        # http://localhost:4174
npm test             # Playwright: сценарии записи, доступность, вёрстка на телефоне
```

Сборки нет: папку `app/` можно выложить на любой статический хостинг (GitHub Pages,
Netlify, свой сервер).

## Ограничения текущей версии

- Записи, гараж и избранное хранятся только на устройстве (localStorage); сервиса для
  владельцев моек и СТО пока нет, поэтому занятость окон — имитация.
- Следующий шаг для реального запуска: общий бэкенд с кабинетом для точек, предоплатой
  с удержанием денег до выполнения заказа (через платёжный сервис с «безопасной сделкой»,
  например UAPAY или Fondy) и уведомлениями.
