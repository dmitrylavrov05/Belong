# RocketBig Telegram-бот

Бот проводит пользователя от первого /start до первого депозита в 1win и сам напоминает тем, кто остановился на полпути.

## Установка на Ubuntu одной командой
```bash
curl -fsSL https://raw.githubusercontent.com/dmitrylavrov05/belong/rocketbig-bot/install.sh | sudo bash
```
Скрипт спросит токен от @BotFather. Остальное заполнено значениями по умолчанию: ID админа, реферальные ссылки RU и BR, промокод `BIGROCKET`. В конце он выведет ссылки для постбэков.

- Логи: `journalctl -u rocketbig -f`
- Настройки: `sudo nano /opt/rocketbig-bot/.env`, затем `sudo systemctl restart rocketbig`
- Обновление: повтори команду установки (настройки и база сохранятся)

## Воронка
1. **Язык**: 🇷🇺 / 🇧🇷.
2. **Проверка 18+**. Если пользователю нет 18, бот вежливо отказывает и больше ему не пишет.
3. **Приветствие**: логотип, бонус до +500%, промокод (копируется нажатием) и план из 3 шагов.
4. **Шаг 1, регистрация**: кнопка с реферальной ссылкой и кнопка «Я зарегистрировался».
5. **Шаг 2, промокод**: где и как ввести `BIGROCKET`.
6. **Шаг 3, первый депозит**: почему первый депозит самый выгодный и как пополнить.
7. **После депозита**: поздравление и советы, как отыграть бонус.

Если человек снова нажмёт /start, бот вернёт его на тот шаг, где он остановился.

## Автонапоминания (ретеншн)
| Где остановился | Когда приходит | О чём сообщение |
|---|---|---|
| Не начал регистрацию | через 1 ч, 24 ч, 3 дня | бонус ждёт → как работает +500% → последнее напоминание |
| Зарегистрировался, не пополнил | через 3 ч, 1 день, 3 дня, 7 дней | активируй бонус → FAQ (промокод, начисление, вывод) → выгода первого депозита → последнее |
| Пополнил | через 1 день | как отыграть бонус, лимиты, ответственная игра |

Правила, которые защищают от блокировок и жалоб:
- не больше 1 автосообщения за 20 часов;
- сообщения уходят только с 10:00 до 22:00 по времени аудитории (RU: МСК, BR: Бразилиа);
- в каждом сообщении есть кнопка «Не присылать напоминания», и есть команда /stop;
- цепочка конечна: после последнего напоминания бот замолкает;
- как только человек переходит на следующий шаг, цепочка начинается заново под этот шаг.

Тексты цепочек лежат в `texts.py`, расписание задаётся словарём `DRIP` там же.

## Отслеживание регистраций и депозитов
Кнопки «Я зарегистрировался» и «Я пополнил» пользователь нажимает сам. Чтобы цифры были точными, подключи постбэки:
1. Бот добавляет к реферальной ссылке Telegram ID пользователя: `&sub1=123456789`.
2. В кабинете партнёра 1win укажи постбэки, которые установщик вывел в конце. Пример:
   `http://IP:8080/postback?secret=СЕКРЕТ&event=ftd&user={sub1}`
   Для регистрации используй `event=reg`.
3. При депозите бот сам отметит пользователя и перестанет слать ему напоминания о пополнении.

Если ссылки ведут через `PUBLIC_URL` (`http://IP:8080/go/...`), бот считает ещё и клики. Порт 8080 должен быть открыт.

## Команды админа
- `/stats`: воронка по RU и BR (18+ → клик → регистрация → промокод → депозит) с конверсией, отписки и блокировки.
- `/broadcast текст`: рассылка всем. Сегменты: `ru`, `pt`, `nodep` (ещё не пополнили), `dep` (уже пополнили).
  Можно ответить `/broadcast nodep` на сообщение с фото или видео, бот скопирует его.
- `/dep 123456789`: вручную отметить депозит.
- Любые сообщения пользователей бот пересылает админу как вопросы в поддержку.

## Ручной запуск (Windows / любой ПК)
1. Переименуй `.env.example` в `.env` и впиши токен.
2. Запусти `start.bat` (Windows) или `./start.sh` (Linux/Mac).
