# Бот объявлений Gruzovoe-Kharkiv

Публикует объявления о грузоперевозках в Telegram-чатах **только там, где админ сам добавил бота и разрешил публикации**.

## Правила, которые бот соблюдает сам
- Не вступает в чаты сам — его добавляет администратор.
- После добавления молчит, пока админ не напишет `/allow <часы>`.
- Публикует не чаще, чем разрешил админ, и **не чаще раза в 24 часа** в любом случае.
- Только днём: с 9:00 до 21:00 по Киеву.
- Чередует 4 текста, чтобы не повторяться.
- `/pause`, `/stop` или удаление бота — публикации сразу прекращаются, вам приходит уведомление.

## Запуск (≈15 минут)
1. В Telegram откройте **@BotFather** → `/newbot` → придумайте имя, например `GruzovoeKharkivBot`. Скопируйте токен.
2. В @BotFather: `/setjoingroups` → Enable (чтобы бота можно было добавлять в группы).
3. Узнайте свой Telegram ID у **@userinfobot**.
4. Напишите своему боту `/start` — так он сможет присылать вам уведомления.
5. Впишите свой номер и сайт в `texts.py`.
6. Запустите на любом сервере или компьютере, который всегда включён (дешёвый VPS, Raspberry Pi):
   ```
   pip install "python-telegram-bot[job-queue]>=21,<22"
   export BOT_TOKEN="123456:ABC..."
   export OWNER_ID="123456789"
   python3 bot.py
   ```

## Команды
**Админ в чате:** `/allow 72` · `/pause` · `/resume` · `/status` · `/stop`
**Вы в личке с ботом:** `/chats` — все чаты и статусы · `/preview` — посмотреть тексты

## Как договориться с админами
Найдите районные чаты Харькова (Салтовка, Алексеевка, ХТЗ, барахолки) и напишите админу:

> Добрий день! Я з Gruzovoe-Kharkiv — вантажне таксі по Харкову.
> Чи можна розміщувати в чаті оголошення про наші послуги? Є бот, який публікує не частіше, ніж ви дозволите (наприклад, раз на 3 дні), і зупиняється однією командою /stop.
> Готові оплатити розміщення або дати мешканцям чату знижку 10%. Скільки це коштуватиме?

Если админ согласен — он добавляет бота `@ВашБот` в чат и пишет `/allow 72`.
